## 🚀 Featured Projects

### 🧠 [Multimodal Emotion Recognition System](https://github.com/MalikShujaatAli) — 2025
> `TensorFlow` `FastAPI` `Microservices` `Flutter` `NLP` `Computer Vision`

A **safety-critical AI system** for multimodal emotion detection across audio, visual, and text streams.

- Architected a **5-layer production pipeline**: Flutter mobile client → 3 FastAPI microservices (text/audio/vision) → fusion gateway with weighted softmax + contradiction detection
- Engineered **dual-layer safety screening**: regex pre-gates + 8B LLM classifier routing to a 70B therapeutic LLM with crisis protocol and locale-aware helpline injection
- Optimized CPU inference via **TFLite float16 quantization** (2.3× latency reduction), `@tf.function` graph compilation, and zero-disk FFmpeg RAM pipelines
- Achieved **100% masked-distress detection** in multimodal vs. 0% text-only (validated via staged vignette replay, n=30, with clinician-informed oracle labels)
